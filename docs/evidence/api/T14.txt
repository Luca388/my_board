# T14 없는 글과 잘못된 ID
# 실행: 2026-10-27 22:23:01 · 서버 TOKEN_TTL=90

## 없는 글 조회 (99999)
$ curl -i http://127.0.0.1:8000/api/posts/99999
HTTP/1.1 404 
Content-Type: application/json

{"code":"NOT_FOUND","message":"게시글이 없습니다."}
-> 예상 404 NOT_FOUND / 실제 404 NOT_FOUND : PASS

## 없는 글 수정 (Alice 정상 토큰)
$ curl -i -X PUT http://127.0.0.1:8000/api/posts/99999 -H 'Authorization: Bearer <ALICE_TOKEN>' -H 'Content-Type: application/json' -d '{"title":"t","content":"c"}'
HTTP/1.1 404 
Content-Type: application/json

{"code":"NOT_FOUND","message":"게시글이 없습니다."}
-> 예상 404 NOT_FOUND / 실제 404 NOT_FOUND : PASS

## 없는 글 삭제 (Alice 정상 토큰)
$ curl -i -X DELETE http://127.0.0.1:8000/api/posts/99999 -H 'Authorization: Bearer <ALICE_TOKEN>'
HTTP/1.1 404 
Content-Type: application/json

{"code":"NOT_FOUND","message":"게시글이 없습니다."}
