# T03 잘못된 비밀번호 및 없는 이메일 로그인
# 실행: 2026-10-27 22:22:49 · 서버 TOKEN_TTL=90

## Alice 이메일 + 틀린 비밀번호
$ curl -i -X POST http://127.0.0.1:8000/api/auth/login -H 'Content-Type: application/json' -d '{"email":"alice@class.test","password":"wrong-password"}'
HTTP/1.1 401 
WWW-Authenticate: Bearer
Content-Type: application/json

{"code":"INVALID_CREDENTIALS","message":"이메일 또는 비밀번호를 확인하세요."}
-> 예상 401 INVALID_CREDENTIALS / 실제 401 INVALID_CREDENTIALS : PASS

## 없는 이메일
$ curl -i -X POST http://127.0.0.1:8000/api/auth/login -H 'Content-Type: application/json' -d '{"email":"nobody@class.test","password":"Classroom!2026"}'
HTTP/1.1 401 
WWW-Authenticate: Bearer
Content-Type: application/json

{"code":"INVALID_CREDENTIALS","message":"이메일 또는 비밀번호를 확인하세요."}
-> 예상 401 INVALID_CREDENTIALS / 실제 401 INVALID_CREDENTIALS : PASS
