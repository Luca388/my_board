# T10 짧은 TTL로 발급 후 실제 만료
# 실행: 2026-10-27 22:22:52 · 서버 TOKEN_TTL=3

TOKEN_TTL=3 으로 서버 재시작 → Alice·Bob 토큰 발급 → 5초 대기

## 만료 토큰 GET /me
$ curl -i http://127.0.0.1:8000/api/me -H 'Authorization: Bearer <EXPIRED_ALICE_TOKEN>'
HTTP/1.1 401 
WWW-Authenticate: Bearer
Content-Type: application/json

{"message":"로그인 시간이 만료되었습니다. 다시 로그인하세요.","code":"TOKEN_EXPIRED"}
